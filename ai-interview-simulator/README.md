# AI Interview Simulator for Tech Roles

A Python + Streamlit web app that uses OpenAI to simulate realistic technical interviews, evaluate your answers, and track your progress over time.

## Features

- **Dynamic Question Generation** — Role-specific questions generated by GPT, tailored to your chosen difficulty
- **AI Answer Evaluation** — Each answer is scored on correctness, clarity, and depth
- **Instant Feedback** — Verdict, strengths, improvement suggestions, and a model answer per question
- **Performance Dashboard** — Charts tracking your scores across sessions
- **GitHub-ready structure** — Modular, clean, commented code

## Supported Roles

Software Engineer, Data Scientist, Machine Learning Engineer, Frontend Developer, Backend Developer, Full Stack Developer, DevOps Engineer, Cloud Architect, Data Engineer, Product Manager (Technical)

## Tech Stack

| Layer | Technology |
|-------|-----------|
| UI | Streamlit |
| AI | OpenAI GPT (via API) |
| Charts | Plotly |
| Data | Pandas |
| Language | Python 3.11+ |

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd ai-interview-simulator
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Set environment variables

Create a `.env` file (never commit this):

```env
OPENAI_API_KEY=sk-...
```

Or export it in your shell:

```bash
export OPENAI_API_KEY="sk-..."
```

Then update `question_generator.py` and `answer_evaluator.py` to use:

```python
api_key=os.environ.get("OPENAI_API_KEY", "")
```

> **Note:** When running on Replit, API access is handled automatically via Replit AI Integrations — no key needed.

### 4. Run the app

```bash
streamlit run app.py
```

## Deploying to Streamlit Cloud

1. Push this folder to a GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io) and connect your repo
3. Set `OPENAI_API_KEY` in the Streamlit Cloud secrets manager
4. Set the main file path to `app.py`
5. Deploy

## Evaluation Scoring

Each answer is scored on three dimensions:

| Dimension | Weight | Description |
|-----------|--------|-------------|
| Correctness | 50% | Technical accuracy |
| Clarity | 25% | Structure and communication |
| Depth | 25% | Detail, examples, trade-off awareness |
